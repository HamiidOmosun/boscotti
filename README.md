# Perfume Mini Store

## Project Description
Perfume Mini Store is a modern, responsive e-commerce web application built with **React**. It allows users to browse, search, and filter a curated collection of perfumes, add items to a shopping cart, and manage their cart efficiently. The project demonstrates key React skills, including **Context API** for state management, dynamic filtering, search functionality, and a fully functional cart system.

---

## Features

- **Product Browsing:** View a collection of perfumes with details such as name, price, and description.  
- **Search Functionality:** Quickly search for perfumes by name using the dynamic search bar.  
- **Filtering System:** Filter perfumes by categories, price, or brand for a refined shopping experience.  
- **Shopping Cart:** Add, remove, and update product quantities in a persistent cart.  
- **Context API:** Global state management for the cart and user interactions without prop drilling.  
- **Responsive Design:** Works seamlessly on desktop and mobile devices.

## Usage

- Browse available perfumes on the homepage.

- Use the search bar to find perfumes by name.

- Apply filters to narrow down products by category or brand.

- Click Add to Cart to include items in your cart.

- View your cart to update quantities or remove items.

- Checkout (if integrated, or just simulate purchase in this mini project).
